# Campusly — Student Management

A responsive student directory for adding, updating, deleting, searching, and filtering student records.

## Live website

https://amberaihacker.github.io/student-management-system/

Every push to `main` deploys the site to GitHub Pages through the workflow in `.github/workflows/pages.yml`.

## Run locally

Open `index.html` in a modern browser. No build step or package installation is required.

## Features

- Student ID, name, department, semester, email, phone, and address records.
- Search across student details; filter by department or semester.
- Add, edit, and delete student records.
- Import and export records as JSON.
- Records persist in the browser's local storage.
- Responsive layout for desktop and mobile screens.

The sample directory is saved in browser storage on first launch. Imported records merge by student ID and replace matching records.
